## Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas na UCSAL** e atuo como **desenvolvedor Full Stack**.

Tenho interesse em desenvolvimento de software e venho construindo projetos próprios para transformar conhecimento em aplicações reais.

Atualmente trabalho principalmente com **Java, JavaScript, HTML, CSS e SQL**, além de estar explorando tecnologias modernas do ecossistema web.

Meu foco é continuar evoluindo tecnicamente, construir projetos cada vez mais completos e transformar meu GitHub em um registro real da minha evolução como desenvolvedor.
